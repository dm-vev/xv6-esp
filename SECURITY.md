# Security Policy

## Supported Versions

Security fixes are provided for the latest `main` branch state and the latest tagged release.
Older tags may be unsupported.

## Reporting a Vulnerability

Please do not open public issues for suspected security vulnerabilities.

Report privately with:

- affected commit/tag
- affected component or path
- reproduction steps
- expected vs actual behavior
- impact assessment

Preferred private channels:

1. GitHub Security Advisories (private report)
2. Project maintainer private contact

## Response Targets

- initial acknowledgement: within 72 hours
- triage decision: within 7 days
- fix plan or mitigation guidance: as soon as reproducible

## Disclosure

After a fix is released, a public disclosure may include:

- impacted versions
- root cause summary
- remediation details
- upgrade guidance
